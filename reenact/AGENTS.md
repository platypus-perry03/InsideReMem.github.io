# Reproduction Project Guidelines

## 목적

- 논문에서 제안한 방법과 실험을 가능한 한 원 논문에 가깝게 재현한다.
- 재현 결과와 논문의 결과를 비교하고 차이가 발생하면 원인을 분석한다.
- 각 논문의 재현 작업은 독립적으로 관리한다.

## 개발 환경

- Python
- NVIDIA GPU
- 필요한 라이브러리와 프레임워크는 논문별 환경에 맞게 사용한다.

## 작업 원칙

- 논문과 공식 구현을 우선 기준으로 사용한다.
- 기존 공식 코드가 있다면 새로 구현하기보다 우선 분석하고 재사용한다.
- 논문에 명시된 설정을 임의로 변경하지 않는다.
- 변경이 필요한 경우 이유와 변경 내용을 기록한다.
- 요청 범위를 벗어난 코드 수정이나 리팩토링은 하지 않는다.
- 기존 파일을 우선 수정하고 불필요한 파일 생성을 피한다.
- 한 번에 큰 변경보다 실행 가능한 작은 단위로 구현하고 검증한다.

## 파일 탐색

- 현재 작업에 필요한 파일만 우선 확인한다.
- dataset, checkpoint, output, log 등 대용량 디렉터리를 불필요하게 전체 탐색하지 않는다.
- 관련 없는 다른 재현 프로젝트는 필요하지 않으면 확인하거나 수정하지 않는다.

## 문서

- 이 파일에는 모든 재현 프로젝트에 공통으로 적용되는 규칙만 기록한다.
- 논문별 모델, 데이터셋, 실험 설정과 진행 상황은 각 논문 폴더의 문서에서 관리한다.
- 필요한 세부사항이 있으면 먼저 해당 논문 폴더의 문서를 확인한다.

## 코드 변경 후

- 변경한 파일과 핵심 변경 사항을 간단히 보고한다.
- 실행 또는 검증에 필요한 명령어가 있으면 함께 제시한다.
- 오류가 발생하면 임의로 우회하기보다 원인을 먼저 확인한다.

## 목적

- 논문에서 제안한 방법과 실험을 가능한 한 원 논문에 가깝게 재현한다.

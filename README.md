# InsideReMem

대규모 언어 모델 내부에서 **Reasoning과 Memorization이 어떻게 다르게 표현되고 처리되는지** 분석하는 연구

## Research Focus

- R/M 내부 representation 차이와 layer별 변화 분석
- 차이에 기여하는 후보 Head / Neuron 식별
- 인과 검증과 계산 경로 분석
- LLM 행동의 이해와 제어 가능성 탐색
